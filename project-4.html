case study — 04 / 07

AI Billing Automation Bot

Developed an AI-powered billing automation system that extracts handwritten invoice data using Groq API and generates digital invoices through a Telegram bot with Cloudinary media storage.

Groq APITelegram BotCloudinary Tesseract OCRPython
Ask about it
the problem

Manual handwritten invoice entry caused errors and slow billing.

Shop owners needed to convert handwritten billing slips into formatted digital PDF invoices instantly without manual re-typing or data entry bottlenecks.

what I built

Telegram bot pipeline with Groq API OCR extraction.

  • Instant image capture and pre-processing pipeline for handwritten receipts.
  • Groq Vision API & Tesseract OCR extraction parsing line items, quantities, and totals.
  • Automated customer matching against store database records.
  • Cloudinary media upload and Telegram PDF invoice delivery in under 5 seconds.
