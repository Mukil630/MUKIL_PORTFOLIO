SGC Desktop Billing App

Developed a desktop billing application using Electron and React for invoice creation, automated PDF generation with Puppeteer, and secure Google Drive cloud backup via OAuth.

ElectronReactPuppeteer OAuthGoogle Drive API
Ask about it
the problem

Local client required offline desktop billing with cloud sync.

The client needed a fast, offline desktop solution for generating customer invoices, computing tax breakdowns, printing receipts, and automatically archiving PDFs safely to Google Drive.

what I built

An Electron & React billing desktop app.

  • Cross-platform desktop application interface engineered with Electron and React.
  • High-fidelity PDF invoice rendering powered by headless Puppeteer.
  • Secure OAuth 2.0 Google Drive API integration for real-time cloud invoice backups.
  • Local SQLite storage ensuring seamless offline functionality and zero data loss.
